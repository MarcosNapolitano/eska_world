# <div align="center">VR World</div>

This is a collection of **C#** scripts used in conjunction with **Unity** in 
order to bring interactivity to a **VR WORLD** developed for the game **VRChat**.

You can launch the world [here](https://vrchat.com/home/launch?worldId=wrld_e7c7135b-9568-4597-a1fe-cdbc8746f3a4)!
:rocket:

## Tech Stack

* C#
* Unity
* VRChat UDON

## Quickview

![Screenshot of the site](https://marcosnapolitano.github.io/Assets/vr-world.webp)

## Features

* **Admin System**: Special players have access to special moderation tools.
* **Private Areas**: Private room only for admin players to reunite in.
* **Vip System**: Players that purchase the VIP package have access to special areas.
* **Dynamic Camera**: Live grabbable in-game camera.
* **Moderation Tools**: Admins can mute players, freeze them, give admin, etc.
* **YouTube Players**: Used to play music or for DJ's to stream their sets.
* **Card Game**: Players can play an argentininan card game called **Truco**.

## Final Notes

You don't need a VR Headset in order to play VRChat, you just need an account
(or an existing Steam account). You can create one through their
website [here](https://vrchat.com).
